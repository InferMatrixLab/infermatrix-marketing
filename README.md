# InferMatrix 宣传与运营材料

集中管理 InferMatrix 涉及的各个项目的宣传与运营材料，方便协作、复用和归档。

## 材料范围

各项目目录可存放项目介绍、宣传文案、发布公告、技术文章、演讲与活动材料，以及相关图片、视频和运营记录。先按项目归档，后续随材料积累按需增加子目录。

## 维护约定

- 材料放入对应项目目录，使用能说明主题的文件名；时效性材料建议带上日期，例如 `2026-10-18-release-announcement.md`。
- 引用技术结论、性能数据或外部素材时，注明来源和适用版本。
- 相关素材与文稿一起归档；包含草稿和已发布版本时，注明状态及发布链接。

## 宣传网站

InferMatrix 宣传网站独立维护于 [InferMatrixLab/infermatrix.github.io](https://github.com/InferMatrixLab/infermatrix.github.io)。本仓库用于材料管理，网站内容与页面代码在网站仓库维护。
