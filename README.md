# InferMatrix 宣传与运营材料

集中管理 InferMatrix 涉及的各个项目的宣传与运营材料，方便协作、复用和归档。

| 目录 | 对应项目仓库 / 用途 |
| --- | --- |
| [infermatrix](./infermatrix/) | InferMatrix 整体品牌与跨项目宣传 |
| [vllm_omni](./vllm_omni/) | [vllm-project/vllm-omni](https://github.com/vllm-project/vllm-omni) |

| [vllm_rlt](./vllm_rlt/) | [ThinkFlowLab/vllm-rlt](https://github.com/ThinkFlowLab/vllm-rlt) |

## 材料范围

各目录统一使用以下子目录归档材料：

- `video/`：宣传视频、演示视频及相关视频素材。
- `image/`：海报、配图、品牌视觉及相关图片素材。
- `blog/`：项目介绍、技术文章、发布公告及其他文字稿件。

InferMatrix 整体品牌与跨项目宣传材料放入 `infermatrix/`，单个项目的材料放入对应项目目录。

## 维护约定

- 材料按项目归属和类型放入对应子目录，使用能说明主题的文件名；时效性材料建议带上日期，例如 `2026-10-18-release-announcement.md`。
- 引用技术结论、性能数据或外部素材时，注明来源和适用版本。
- 相关素材与文稿一起归档；包含草稿和已发布版本时，注明状态及发布链接。
